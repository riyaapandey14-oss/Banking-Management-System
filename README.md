# Banking Management System

A full-stack Banking Management System built using Python, FastAPI, PostgreSQL, HTML, CSS, and JavaScript.

## Features

- User management
- Bank account management
- Deposit money
- Withdraw money
- Check account balance
- View transaction history
- PostgreSQL database connectivity
- Simple web-based interface

## Technologies Used

- Python
- FastAPI
- PostgreSQL
- HTML
- CSS
- JavaScript
